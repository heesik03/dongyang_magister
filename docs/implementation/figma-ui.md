# 새로운 PC 화면 구현

기준: Figma 새로운 화면(18:3), 2026-11-01 종합 개선 결과.

## 저장·API 계약

- 원고 content는 LONGTEXT, 설정 content는 TEXT에 마크다운 원문을 저장한다. HTML 변환·마크다운 제거·공백 정규화를 하지 않는다. 원고 200,000자, 설정 10,000자 제한과 버전 충돌 검사를 유지한다. 컬럼 형식 변경이나 마이그레이션은 필요하지 않다.
- GET /api/work 및 GET /api/work/{workId}, 작품 수정 응답에 chapterCount, settingCount, latestChapterId, latestChapterTitle을 추가한다. 최근 회차는 가장 큰 chapterNo이며, 회차가 없으면 최근 회차 두 필드는 null이다.
- 목록은 기존 검색·장르·페이지 계약을 유지한다. 인증한 소유자에 한정해 현재 페이지 ID들을 한 번에 요약 조회한다. 본문을 로딩하지 않으며, 전체 조회는 페이지 크기와 무관하게 최대 세 SQL 질의다. 기존 페이지 크기 상한 100을 유지한다.
- 생성·수정·삭제·세션·CSRF·AI 전송 확인·원고 충돌 복구는 기존 API를 재사용한다. UI 디자인을 이유로 권한·버전·전송 동의 검사를 생략하지 않는다.

## 마크다운

- react-markdown 10.1.0과 remark-gfm 4.0.1로 React 19에서 안전한 미리보기를 제공한다. 기존 textarea와 자동 저장 흐름을 유지해 무거운 편집기를 추가하지 않는다.
- h1~h4, 굵게, 기울임, 취소선, 인용, 글머리·번호 목록을 지원한다. HTML은 실행하지 않고, 이미지와 링크·표 기능은 제공하지 않는다. 미리보기와 저장 원문을 분리한다.
- 원고와 설정 편집에 같은 도구를 사용한다. 근거의 문자열과 오프셋은 저장 원문을 기준으로 유지한다.
- 참고: https://github.com/remarkjs/react-markdown, https://github.com/remarkjs/remark-gfm

## 디자인

- 요청한 Pretendard Thin 100 선언과 일반·중간·굵은 서체를 사용한다. 배경 #F7F6F3, 사이드바 #EFECE6, 본문·주요 버튼 #191919, 링크 #1769B2, 보조 글자 #686762를 기준으로 한다.
- PC 기본 사이드바 248px, 헤더 64px, 푸터 80px, 콘텐츠 여백 32px. 좁은 화면에서는 요소를 줄바꿈하고 모바일 탐색을 제공한다.

## 사건 카드 설명

- 사건에 선택적인 description(최대 2,000자)을 추가한다. 기존 workspace JSON 저장 구조를 사용하므로 테이블 변경은 필요하지 않다. 이전 JSON의 누락·null 설명은 빈 문자열로 읽는다. 원고 인용·회차 참조·저장 버전 검사를 유지한다.
- 프런트에서는 사건 설명을 입력·수정하고 근거 회차별로 필터링한다. 설정의 연결 회차와 검토 후보는 실제 저장된 분석 참조에서만 표시한다.
