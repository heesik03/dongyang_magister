# Figma 신규 PC UI 적용 검증 (2026-11-01)

## 변경 범위

- 인증·보관함·작품 탐색·원고·설정·사건·작품 관리 모달·404/500/연결 실패 화면. Figma의 Warm Stone & Obsidian Ink 색상과 간격을 적용하고, 서체는 사용자가 지정한 Pretendard로 적용했다.
- react-markdown 10.1.0 + remark-gfm 4.0.1. 원문 저장과 미리보기를 분리하며 HTML, 이미지, 링크, 표는 렌더링하지 않는다. 편집 도구는 h1~h4, 강조, 기울임, 취소선, 인용, 목록이다.
- 보관함 요약 API, 사건 description(2,000자), 이전 JSON 호환 처리. 기존 TEXT/LONGTEXT/JSON 저장 컬럼으로 지원하므로 테이블 마이그레이션은 없다.

## 자동 검사

- 프런트: pnpm test — 14개 파일, 101개 테스트 통과.
- 프런트: pnpm lint, pnpm build, pnpm format:check 검사.
- 백엔드: .\gradlew.bat build — 122개 테스트, 실패·오류·건너뜀 0. 실제 Gemini와 별도 mysqlTest는 이 태스크에서 제외한다.
- 추가 계약: 원고 마크다운 생성·수정·조회 동일성, 설정 마크다운 조회 동일성, 보관함 개수·최근 회차, 페이지 크기와 무관한 SQL 3회, 사건 설명 저장·크기 제한·이전 JSON 호환.

## 실제 브라우저 연동

8080 기본 개발 서버와 MySQL 8.0.41을 사용했다. 5173 프런트와 실제 세션·CSRF 흐름으로 아래를 확인했다.

- 가입 중복 확인·비밀번호 조건·가입 후 로그인.
- 작품 3개와 회차·설정 생성 후 보관함의 실제 개수·최근 회차 표시.
- 원고 마크다운 자동 저장 후 API로 원문 동일성 확인, 미리보기와 편집 전환.
- 설정 마크다운을 미리보기 상태에서 저장하고 새로고침 뒤 재조회.
- 사건 설명을 저장하고 새로고침 뒤 유지되는지 확인.
- 작품 관리 모달, 404, 연결 실패 화면.
- 1920px·1366px PC와 390px 모바일에서 수평 넘침 없음. 브라우저 실행 오류 없음. 스크린샷을 확인하고 모바일 사이드바 너비와 편집기 배치를 보정했다.

검증용으로 생성한 작품은 해당 검증 계정의 소유권·버전 API로 정리했다. 실제 Gemini 호출은 수행하지 않았다.

추가 확인: 세션 조회 연결을 브라우저에서 차단한 뒤 오류 화면의 다시 시도로 로그인 화면에 복귀했다. 500 화면도 직접 확인했으며 Pretendard 400·700 서체가 실제 로드됐다.
