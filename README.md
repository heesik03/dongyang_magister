# Magister

장기 연재 소설·웹소설 작가를 위한 **AI 소설 집필 보조 및 설정·개연성 검토 서비스**입니다.

회차가 길어질수록 작가는 인물의 능력, 성격, 세계관 규칙, 이전 회차의 사건을 모두 기억하며 새 원고를 쓰기 어렵습니다. Magister는 작가가 정리한 **확정 설정**과 **이전 회차 원고**, 그리고 과거 검토에서 남긴 **작가의 판단 기록**을 기준으로 원고를 집필·다듬고 설정 충돌과 개연성을 점검할 수 있도록 돕습니다.

<br />

## 주요 기능

### 1. 작품 및 설정집 관리

- 작품별로 인물·세계관·장소·사건·능력 설정을 정리합니다.
- 설정을 **확정**, **아이디어**, **보류** 상태로 구분합니다. 아직 구상 중인 `아이디어`는 제외하고, 연재 설정으로 굳어진 `확정` 설정만 AI 집필 보조와 개연성 검토에 사용합니다.
- 인물 설정에서는 외형 묘사와 연출 방향을 입력해 **AI 캐릭터 시안 이미지**를 바로 생성하고 대표 이미지로 지정할 수 있습니다.

### 2. 회차 원고 집필 및 AI 집필 도우미

- 회차별 Markdown 원고를 작성하고 저장하며, 여러 탭·기기에서 저장 충돌이 발생하면 서버 원고와 내 초안을 비교해 원하는 버전을 복구할 수 있습니다.
- 편집기 안의 **AI 집필 도우미**에서 참고할 확정 설정(최대 5개)을 고르고 **다음 문장 이어쓰기**, **장면 묘사 보강**, **대사 다듬기** 제안을 받아 원고 끝에 추가하거나 선택한 문장 구간에 바로 적용할 수 있습니다.
- 외부에서 작성한 `.txt`, `.md`, `.docx`, `.pdf` 원고 파일을 미리 확인한 뒤 새 회차로 가져오거나 현재 회차를 교체할 수 있으며, 작성한 회차 또는 작품 전체 원고를 파일로 내보낼 수 있습니다.

### 3. 범위 선택형 AI 검토

- 검토할 회차와 함께 참고할 **확정 설정**과 **이전 회차**를 작가가 직접 선택해 원클릭으로 AI 검토를 실행합니다.
- 검토 결과는 **설정 충돌 후보**와 **설명 보완**으로 나뉘며, 문제 문장·검토 이유·보완 제안과 함께 근거가 된 설정·이전 회차 원문을 핵심 위주로 간결하게 보여 줍니다.
- 각 검토 후보에서 문제 문장과 근거 설정·이전 회차의 정확한 원문 위치로 바로 이동해 맥락을 확인할 수 있습니다.

### 4. 후보별 작가 판단 기록

- AI 검토 후보마다 **수용**, **보류**, **의도된 설정**으로 작가의 결정을 남길 수 있습니다.
- 반전이나 일시적 각성처럼 작가가 의도한 전개는 사유와 적용 범위(`이 장면만` 또는 `회차 구간`), 조건을 적어 두면 다음 회차 검토에서 저장한 판단을 함께 참고합니다.

### 5. 사건 타임라인

- 회차 원고에서 주요 사건 후보를 AI로 바로 추출해 타임라인에 반영하거나, 직접 사건을 추가·수정·삭제하고 근거 문장과 연결합니다.
- **이야기 속 순서**와 **원고에 나온 순서**를 나란히 비교해 회상·역순 구성을 확인하고, 아직 순서가 정해지지 않은 사건은 분리해 관리합니다.

### 6. 마이페이지

- 작가 필명 수정 및 창작 공간 현황(보유 작품·저장된 회차·미검토 후보·최근 집필 원고 이어쓰기)을 확인합니다.
- 비밀번호 변경(변경 시 전체 기기 세션 로그아웃 및 미저장 원고 보호)과 회원 탈퇴(진행 중 AI 작업 취소 및 모든 창작 데이터 영구 삭제)를 지원합니다.

## 기술 스택 및 실행 방법

| 영역 | 기술 구성 |
| --- | --- |
| **Frontend** | React 19, TypeScript 6, Vite 8, React Router 7, Zustand, Axios, Vitest, pnpm |
| **Backend** | Java 21, Spring Boot 4.1.1, Spring Security (세션 + CSRF), Spring Data JPA, Bean Validation, Gradle Wrapper |
| **Database** | MySQL |
| **AI** | Google Gemini API |

<br />

```bash
# 프런트엔드 실행 (http://localhost:5173)
cd frontend
pnpm install --frozen-lockfile
pnpm dev

# 백엔드 실행 (http://localhost:8080)
cd backend
./gradlew bootRun
```

## 프로젝트 구조

```text
magister/
├── frontend/
│   ├── src/
│   │   ├── features/
│   │   │   ├── account/      # 마이페이지 (프로필·현황·비밀번호 변경·회원 탈퇴)
│   │   │   ├── analysis/     # AI 검토 범위 선택 및 비동기 상태 조회
│   │   │   ├── auth/         # 로그인·회원가입·인증 라우트
│   │   │   ├── errors/       # 오류 및 404 안내 화면
│   │   │   ├── manuscript/   # 회차 원고 편집기·AI 집필 도우미·파일 가져오기/내보내기
│   │   │   ├── review/       # AI 검토 결과 확인 및 후보별 작가 판단 기록
│   │   │   ├── settings/     # 작품 설정집 관리 및 캐릭터 시안 이미지 생성
│   │   │   ├── timeline/     # 사건 타임라인 관리·AI 사건 추출·서술/시간순 비교
│   │   │   ├── works/        # 작품 보관함·작품 관리
│   │   │   └── workspace/    # 작업 공간 동기화 및 충돌 복구
│   │   └── shared/           # 공통 레이아웃·마크다운 편집기·다이얼로그·HTTP 클라이언트
│   └── tests/                # 프런트엔드 테스트
└── backend/
    └── src/main/java/com/magister/backend/
        ├── domain/           # work, chapter, setting, timeline, analysis, decision, gemini, user 등 도메인 단위 구성
        └── global/           # 보안(세션/CSRF), 공통 응답, 예외 처리
```
