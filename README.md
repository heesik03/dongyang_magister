# Magister

작품의 설정과 원고를 함께 검토하고, 역사적 근거와 사건 흐름을 보여주는 **AI 창작 검토 서비스**입니다.

## 프로젝트 개요

Magister는 소설·웹소설 작가를 핵심 사용자로 하며, 만화·웹툰·게임 시나리오 등으로 활용 범위를 확장하는 것을 목표로 합니다. 세계관 규칙, 인물 설정, 선택한 이전 원고를 바탕으로 설정 충돌과 설명이 부족한 전개를 찾아 창작자의 검토를 돕습니다.

역사물은 작품의 시대·지역에 맞는 자료와 원고의 표현을 비교하고, 사건 타임라인으로 전체 흐름을 파악하도록 합니다. 검토 결과에는 원문과 관련 설정·자료를 연결하며, 오류 가능성·설명 부족·의도된 각색을 구분해 최종 판단은 사용자에게 맡깁니다.

상세 요구사항과 일정은 [Notion 프로젝트 기획서](https://app.notion.com/p/_Magister-3eac29dbef40809b8150f5dc8e403d2e)를 기준으로 합니다.

## 주요 기능 계획

아래 기능은 기획 단계의 개발 목표입니다.

| 기능 | 첫 MVP에서 제공할 내용 |
| --- | --- |
| 작품·설정집 관리 | 작품별 장르, 시대·지역, 세계관 규칙, 인물 설정, 의도된 각색 관리 |
| 원고 입력·분석 범위 선택 | 한국어 원고를 회차·장면 단위로 붙여 넣고 참고할 설정·이전 원고 선택 |
| 설정·맥락 일관성 검토 | 세계관 규칙, 인물 정보, 사건 순서·인과관계의 충돌 후보와 원문 위치 제시 |
| 인물 개연성 검토 | 성격·목표와 행동·대사를 비교하여 추가 설명이 필요한 부분 제안 |
| 근거 중심 검토 리포트 | 문제 유형, 심각도, 원문, 근거, 판단 이유, 수정 방향과 수용·보류·의도된 설정 처리 |
| 역사 고증 보조 | 한 시대·지역과 선별된 공개 자료를 대상으로 표현을 대조하고 출처 표시 |
| 사건 타임라인 | 사건·등장인물·시점을 시간순으로 보여주고 원문 이동·시점 수정 지원 |

인물 관계도, 복선·미회수 사건 관리, 이미지·만화 컷 인식, 원고 자동 집필, 실시간 공동 편집, 모든 시대·국가 고증, 팬 커뮤니티는 첫 MVP에 포함하지 않습니다.

## 주요 사용 흐름

1. 작품을 생성하고 장르, 시대·지역, 고증 엄격도와 의도된 각색을 입력합니다.
2. 세계관 규칙과 인물의 성격·목표·관계, 주요 사건을 등록합니다.
3. 검토할 회차·장면과 참고할 이전 원고를 선택합니다.
4. 설정 일관성, 인물 개연성, 역사 고증 중 필요한 분석을 실행합니다.
5. 원문·근거와 검토 결과를 확인하고 사건 타임라인을 살펴봅니다.
6. 결과를 수용·보류하거나 의도된 설정으로 표시하고 수정 후 다시 검토합니다.

## 설계 원칙

- 사용자 확인 없이 AI가 추출한 설정으로 확정 설정을 덮어쓰지 않습니다.
- 실제 분석한 원고 범위를 표시하고, 사실과 추론을 구분합니다.
- 고증은 확인한 출처를 제시하며, 근거가 부족하거나 상충하면 판단을 유보합니다.
- 사건 시점과 관계 추출 결과는 사용자가 수정할 수 있도록 설계합니다.
- 원고는 기본 비공개로 관리하고 저장·삭제 및 외부 AI 전송 범위를 안내하며, 서비스 학습용 이용은 별도 동의를 받도록 설계합니다.

## 기술 구성 및 현재 상태

| 영역 | 저장소 구성 |
| --- | --- |
| 프런트엔드 | React 19.2 계열, TypeScript 6.0 계열, Vite 8.3 계열, ESLint, pnpm |
| 백엔드 | Java 21, Spring Boot 4.1.1, Gradle Wrapper, Spring MVC, JPA, Bean Validation |
| 데이터베이스 | MySQL 사용 예정, 드라이버 의존성 포함 |
| AI | Google Gemini API 사용 예정 |

2026년 10월 12일 기준 프런트엔드는 Vite 초기 화면이며, 백엔드는 애플리케이션 시작 클래스와 컨텍스트 테스트가 구성되어 있습니다. 도메인 기능과 AI 연동은 아직 구현되지 않았습니다. AI는 Gemini API를 사용할 예정입니다.

## AI 활용 계획

AI는 **Google Gemini API**를 사용할 예정입니다. 사용자가 확정한 설정과 선택한 원고를 바탕으로 다음 기능에 활용합니다.

| 도메인 기능 | Gemini 활용 방식 | 사용자에게 제공할 결과 |
| --- | --- | --- |
| 설정·맥락 일관성 검토 | 원고에서 인물 정보·세계관 규칙·사건을 추출하고 확정 설정 및 선택한 이전 원고와 비교 | 설정 충돌 후보, 해당 원문과 관련 설정, 판단 이유 |
| 인물 행동·대사 개연성 검토 | 인물의 성격·목표·이전 행동과 현재 장면을 함께 해석 | 설명이 부족한 행동·대사와 검토 질문, 보완 방향 |
| 역사 고증 보조 | 시대·지역에 따른 호칭·제도·복식·생활상 등의 확인 항목과 검색어를 추출하고 확보한 자료의 관련 구절과 원고를 대조 | 고증 충돌 후보, 출처와 관련 구절, 근거 부족·자료 상충 여부 |
| 근거 중심 검토 리포트 | 검토 후보를 유형·심각도별로 정리하고 원문·설정·자료를 연결해 설명과 수정 방향 생성 | 근거를 확인할 수 있는 검토 카드와 수용·보류·의도된 설정 선택 |
| 사건 타임라인 | 장면별 사건·등장인물·시간 표현을 추출하고 사건 순서 초안 구성 | 원문과 연결된 타임라인, 시점 미상 표시와 사용자 수정 |

AI 결과는 검토 후보로 제시하며, 인물의 변화나 의도된 반전·각색을 오류로 단정하지 않습니다. 역사 고증은 실제 확인한 자료를 근거로 삼고, 근거가 없거나 상충하면 판단을 유보합니다. 최종 판단과 확정 설정의 변경은 사용자가 결정합니다.
