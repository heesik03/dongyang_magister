# Magister

장기 연재 소설·웹소설 작가를 위한 **설정·개연성 검토 및 원고 관리 서비스**입니다.

회차가 길어질수록 작가는 인물의 능력, 성격, 세계관 규칙, 이전 회차의 사건을 모두 기억하며 새 원고를 쓰기 어렵습니다. Magister는 작가가 정리한 **확정 설정**과 **이전 회차 원고**, 그리고 과거 검토에서 남긴 **작가의 판단 기록**을 기준으로 새 원고를 점검할 수 있도록 돕습니다.

<br />

## 주요 기능

### 1. 작품 및 설정집 관리

- 작품별로 인물·세계관·장소·사건·능력 설정을 정리합니다.
- 설정을 **확정**, **아이디어**, **보류** 상태로 구분합니다. 아직 구상 중인 `아이디어`는 검토 기준에서 제외하고, 연재 설정으로 굳어진 `확정` 설정만 AI 검토에 사용합니다.

### 2. 회차 원고 집필 및 가져오기·내보내기

- 회차별 Markdown 원고를 작성하고 자동 저장합니다.
- 외부에서 작성한 `.md`, `.txt` 원고를 새 회차로 가져오거나 현재 회차 원고를 파일로 내보낼 수 있습니다.
- 여러 탭·기기에서 저장 충돌이 발생하면 서버 원고와 내 초안을 비교해 원하는 버전을 복구할 수 있습니다.

### 3. 범위 선택형 AI 검토

- 검토할 회차와 함께 참고할 **확정 설정**과 **이전 회차**를 작가가 직접 선택하고, 외부 AI에 전송될 원문을 미리 확인한 뒤 검토를 실행합니다.
- 검토 결과는 **설정 충돌 후보**와 **설명 보완**으로 나뉘며, 문제 문장과 근거 설정·이전 회차의 정확한 원문 위치로 바로 이동할 수 있습니다.
- 각 검토 후보는 **확인된 사실 → 해석이 필요한 부분 → 부족한 정보 → 가능한 보완 방향(전제 포함)** 순서로 정리해 보여 줍니다.
- 한 회차에서 반복되는 동일 쟁점은 그룹으로 묶어 요약하고, 원고 수정 후 재검토 시 직전 결과와 비교해 **유지된 쟁점 / 새 후보 / 다시 나오지 않은 후보**를 구분해 보여 줍니다.
- 작품 전체 회차의 검토 상태(`최신 원고 분석됨` / `수정 전 원고 기준` / `미분석`)와 미검토 건수를 한눈에 비교할 수 있습니다.

### 4. 작가 판단 기록 (Decision Ledger)

- AI 검토 후보마다 **수용**, **보류**, **의도된 설정**으로 작가의 결정을 남길 수 있습니다.
- 반전이나 일시적 각성처럼 작가가 의도한 전개는 적용 범위(`이 장면만` 또는 `회차 구간`)와 조건을 적어 두면, 다음 검토 시 해당 조건 안에서는 같은 지적을 반복하지 않습니다.

### 5. 사건 타임라인

- 회차 원고에서 주요 사건 후보를 AI로 추출하거나 직접 등록하고 근거 문장과 연결합니다.
- **회차 서술 순서**와 **이야기 속 시간순**을 나란히 비교해 회상·역순 구성을 확인하고, 아직 시점이 정해지지 않은 사건은 `시점 미상`으로 분리해 관리합니다.

### 6. 마이페이지

- 작가 필명 수정 및 창작 공간 현황(보유 작품·저장된 회차·미검토 후보·최근 집필 원고 이어쓰기)을 확인합니다.
- 비밀번호 변경(변경 시 전체 기기 세션 로그아웃 및 미저장 원고 보호)과 회원 탈퇴(진행 중 AI 작업 취소 및 모든 창작 데이터 영구 삭제)를 지원합니다.

## 기술 스택 및 실행 방법

| 영역 | 기술 구성 |
| --- | --- |
| **Frontend** | React 19, TypeScript 6, Vite 8, React Router 7, Zustand, Axios, Vitest, pnpm |
| **Backend** | Java 21, Spring Boot 4.1.1, Spring Security (세션 + CSRF), Spring Data JPA, Bean Validation, Gradle Wrapper |
| **Database** | MySQL |
| **AI** | Google Gemini API |

<br />

```bash
# 프런트엔드 실행 (http://localhost:5173)
cd frontend
pnpm install --frozen-lockfile
pnpm dev

# 백엔드 실행 (http://localhost:8080)
cd backend
./gradlew bootRun
```

## 프로젝트 구조

```text
magister/
├── frontend/
│   ├── src/
│   │   ├── features/
│   │   │   ├── account/      # 마이페이지 (프로필·현황·비밀번호 변경·회원 탈퇴)
│   │   │   ├── analysis/     # AI 검토 범위 선택·전송 미리보기·비동기 상태 조회
│   │   │   ├── auth/         # 로그인·회원가입·인증 라우트
│   │   │   ├── manuscript/   # 회차 원고 편집기·파일 가져오기/내보내기
│   │   │   ├── review/       # 검토 노트·회차별 현황·수정 전후 비교·작가 판단 기록
│   │   │   ├── settings/     # 작품 설정집 관리
│   │   │   ├── timeline/     # 사건 타임라인·사건 추출·서술/시간순 비교
│   │   │   ├── works/        # 작품 보관함·작품 관리
│   │   │   └── workspace/    # 자동 저장 및 충돌 복구
│   │   └── shared/           # 공통 레이아웃·마크다운 편집기·다이얼로그·HTTP 클라이언트
│   └── tests/                # 프런트엔드 테스트
└── backend/
    └── src/main/java/com/magister/backend/
        ├── domain/           # user, work 등 도메인 단위로 분할
        └── global/           # 보안(세션/CSRF), 공통 응답, 예외 처리, DB 마이그레이션
```
